  REQUIRED (build machine):
  ┌─────────────────────────────────────────────────────────┐
  │  Node.js   : 20.20.2  (exact target; ≥20.x acceptable) │
  │  npm       : 10.8.2   (exact target; ≥10.x acceptable) │
  │  OS        : Windows 10/11, macOS 12+, Ubuntu 20.04+   │

  │  Disk      : 350 MB installed                          │
  │  Display   : 1280×720 minimum, 1920×1080 recommended   │
  │  GPU       : Any with hardware-accelerated Canvas2D    │
  │  No Node.js required on end-user machine               │
  └─────────────────────────────────────────────────────────┘

    node --version    → should print v20.20.2 (or v20.x.x)

    Using nvm (recommended):
      nvm install 20.20.2
      nvm use 20.20.2

    Using fnm (Windows):
      fnm install 20.20.2
      fnm use 20.20.2

    Direct download: https://nodejs.org/en/download

3. QUICK START (3 COMMANDS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  From inside the travan-aero-simulator/ directory:

    npm install                # Install all dependencies (~60 seconds)
    npm run build              # Compile React renderer (~5 seconds)
    npm start                  # Launch the desktop application

  That's it. The window opens immediately.

  To build a distributable Windows installer:
    npm run dist               # → dist-electron/TravanAeroSimulator-2.0.0-Setup.exe

4. FULL INSTALLATION — STEP BY STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1 — Verify Node and npm versions
  ──────────────────────────────────────
    node --version
    # Expected: v20.20.2 or any v20.x
    npm --version
    # Expected: 10.8.2 or any 10.x

  STEP 2 — Extract the project
  ─────────────────────────────
    # Windows (PowerShell)
    Expand-Archive travan-aero-simulator.zip -DestinationPath C:\Projects\
    cd C:\Projects\travan-aero-simulator

    # macOS / Linux
    unzip travan-aero-simulator.zip
    cd travan-aero-simulator

  STEP 3 — Install dependencies
  ──────────────────────────────
    npm install

    # This installs:
    #   react, react-dom         ← UI framework
    #   electron 29              ← Desktop runtime
    #   vite 5, @vitejs/plugin-react  ← Build tool
    #   electron-builder 24      ← Packager/installer generator
    #   electron-store           ← Persistent settings storage
    #   electron-log             ← File logging
    #   concurrently, wait-on    ← Dev tooling

    # If you see ERESOLVE errors, run:
    npm install --legacy-peer-deps

    # Expected output: "added 486 packages"

  STEP 4 — Build the renderer
  ─────────────────────────────
    npm run build

    # Expected output:
    #   ✓ 45 modules transformed.
    #   dist/index.html   1.00 kB
    #   dist/assets/*.js  241 kB
    #   ✓ built in ~2s

  STEP 5 — Launch the application
  ────────────────────────────────
    npm start

    # The Travan Aero Simulator window opens (1680×980 default).
    # A development DevTools window opens if you are in dev mode.

  STEP 6 (optional) — Run in full dev mode with hot reload
  ─────────────────────────────────────────────────────────
    npm run dev
    # Starts Vite dev server on localhost:5173 AND Electron simultaneously.
    # Changes to any .jsx/.js file rebuild and reflect live.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. DEVELOPMENT MODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    npm run dev

  This uses concurrently to:
    1. Start the Vite dev server (hot-module replacement on port 5173)
    2. Wait for the server to be ready
    3. Launch Electron pointing at http://localhost:5173

  DevTools open automatically in detached mode.

  Hot reload: edit any file in src/renderer/src/ → browser refreshes.
  Electron IPC: edit src/main/main.js → requires npm run dev restart.

    • Per-user installation (no admin rights needed by default)
    • Licence agreement screen (assets/LICENSE.txt)

  INSTALLER SIZE:
    Expected: ~120–150 MB (Electron runtime bundled)

  DISTRIBUTE:
    Share TravanAeroSimulator-2.0.0-Setup.exe.
    Double-click to install. Runs on any Windows 10/11 x64 machine.
    No Node.js required on the target machine.

13. SIMULATION MODULES — ENGINEERING DETAIL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ── ATMOSPHERE (atmosphere.js) ────────────────────────────────────────────
  Standard: ICAO Doc 7488 / ISO 2533
  Troposphere (0–11,000 m):
    T   = T0 − L·h               T0=288.15K, L=0.0065 K/m
    P   = P0·(T/T0)^(g/RL)
    ρ   = P/(R·T)                R = 287.058 J/(kg·K)
  Stratosphere (>11,000 m):
    T   = 216.65 K (isothermal)
    P   = P11·exp(−g·Δh/R·T)
  Viscosity: Sutherland's law (μ accurate to 0.1% over 200–600 K)
  Outputs: T, P, ρ, a (speed of sound), μ, ν

  ── AERODYNAMICS (aerodynamics.js) ───────────────────────────────────────
  Method: Vortex-lattice / lifting-line with Prandtl-Glauert correction

  Compressibility:
    β = √(1 − M²)                Prandtl-Glauert factor

  Lift curve slope (Helmbold):
    a_wing = (2π/β) / (1 + 2cosΛ/(AR·β))

  Lift coefficient:
    CL = a_wing · (α − αL0)     αL0 from airfoil database

  Oswald efficiency (Raymer correlation):
    e = 1.78·(1 − 0.045·AR^0.68) − 0.64, corrected for sweep & taper

  Induced drag:
    CDi = CL² / (π·AR·e)

  Profile drag (Raymer empirical):
    Cf  = 0.074 / Re^0.2        turbulent flat-plate
    CD0 = Cf·(1 + 2·t/c + 60·(t/c)⁴)·S_wet/S

  Fuselage drag:
    CD_fuse = 0.0025 + 0.15/f²   f = fineness ratio L/D

  Pressure distribution:
    Chordwise Cp(x/c) from thin-aerofoil theory (linear, per station)
    Upper/lower surfaces resolved for Cp chart

  Stall estimate:
    CLmax = 1.2 + 0.12·(t/c)/0.12 + 0.05·camber·50

  ── STRUCTURAL FEA (fea.js) ──────────────────────────────────────────────
  Model: Euler-Bernoulli cantilever beam + thin-walled closed box spar
  Load:  Elliptic spanwise lift distribution (conservative for FAR/CS-25)

  Section properties per spanwise station (taper-varying):
    I = 2·b_cap·t_f·(h/2)² + 2·(t_w·h³/12)    [area moment]
    A_shear = 2·h·t_w                           [shear area]

  Bending moment (elliptic load, analytical):
    M(y) = (2L/πs)·s²·[√(1−u²)/2 − u·(π/2−arcsin u)/2 + ...]
    where u = y/s

  Stress:
    σ_bend = M·(h/2) / I        bending stress at extreme fibre
    τ      = V / A_shear        shear stress in web
    σ_VM   = √(σ² + 3τ²)       Von Mises criterion

  Deflection: double numerical integration of M/EI (trapezoidal rule)

  Safety factor: SF = σ_yield / σ_VM_max
  Flutter speed: empirical Bisplinghoff approximation

  ── MACH / SHOCK (mach.js) ───────────────────────────────────────────────
  Critical Mach (Küchemann + sweep correction):
    Mcc   = 1 / (1 + 0.6·t/c + 0.3·camber)
    Mcrit = Mcc · cos(Λ)

  Normal shock relations (γ = 1.4):
    p2/p1  = 1 + 2γ/(γ+1)·(M1²−1)
    T2/T1  = (p2/p1)·[2+(γ−1)M1²] / [(γ+1)M1²]
    M2     = √[(M1²(γ−1)/2+1) / (γM1²−(γ−1)/2)]
    p0 recovery = Rayleigh Pitot formula

  Oblique shock: theta-beta-M relation, Newton's method iteration

  Prandtl-Meyer expansion:
    ν(M) = √((γ+1)/(γ−1))·arctan√((γ−1)(M²−1)/(γ+1)) − arctan√(M²−1)

  Wave drag rise (Lock approximation):
    ΔCD = 20·(M − Mcrit)⁴

  ── POLAR SWEEP ──────────────────────────────────────────────────────────
  Sweeps AoA from αmin to αmax in 0.5° steps.
  Full aerodynamic solve at each step.
  Finds best L/D angle and CLmax angle.
  Results tabulated in left panel.

14. GEOMETRY IMPORT (STL / OBJ / ASSEMBLY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  │  .json   │ TAS Assembly JSON (see format below)              │
  │  .asm    │ Alias for Assembly JSON                            │

  HOW TO IMPORT:
    1. Click "📎 IMPORT STL / OBJ" in the Design left panel
    2. Browse and select your geometry file
    3. TAS parses the mesh, normalises it to ±4 unit bounding cube
    4. Geometric features are extracted (span, chord, t/c, S_ref, AR)
    5. Parameters auto-populate in the left panel
    6. Review extracted values and adjust if needed
    7. Run simulation normally — solver uses the extracted parameters

  PIPELINE:
    File → Parse triangles → Normalise to simulator space →
    Extract bbox & dimensions → Compute aero features →
    Painter's-algorithm renderer (depth-sorted faces, Phong lighting)

  ── INSTALLATION ISSUES ───────────────────────────────────────────────────

  PROBLEM: npm install fails with ERESOLVE
  SOLUTION:
    npm install --legacy-peer-deps

  PROBLEM: Electron binary fails to download (403 / network timeout)
  SOLUTION:
    # Skip binary download during npm install:
    ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install --legacy-peer-deps
    # Then download Electron v29 manually from:
    # https://github.com/electron/electron/releases/tag/v29.1.0
    # Extract and place electron.exe in node_modules/electron/dist/

  PROBLEM: node: command not found
  SOLUTION:
    Install Node.js 20.20.2 from https://nodejs.org
    Or use nvm: nvm install 20.20.2 && nvm use 20.20.2

  PROBLEM: vite build fails — "Cannot find module"
  SOLUTION:
    rm -rf node_modules dist
    npm install --legacy-peer-deps
    npm run build

  PROBLEM: ERESOLVE peer dependency conflict (React version)
  SOLUTION:
    npm install --legacy-peer-deps --force

  ── RUNTIME ISSUES ────────────────────────────────────────────────────────

  PROBLEM: App window opens blank / white screen
  SOLUTION:
    1. Run npm run build first before npm start
    2. Check that dist/index.html exists
    3. Open DevTools (Ctrl+Shift+I) and check Console for errors

  PROBLEM: 3D viewport is black / not rendering
  SOLUTION:
    • Enable hardware acceleration in Electron:
      In main.js, add before app.whenReady():
        app.commandLine.appendSwitch('enable-accelerated-2d-canvas')
    • Update graphics drivers
    • Try: View → Force Reload (Ctrl+R)

  PROBLEM: STL import fails — "contains no valid geometry"
  SOLUTION:
    • Verify the file is not corrupt: open in MeshLab or Blender
    • For binary STL: ensure the header is exactly 80 bytes
    • For ASCII STL: ensure "solid" / "endsolid" tags are present
    • For OBJ: ensure face indices are 1-based (standard OBJ format)
    • Max recommended size: 50,000 triangles for smooth performance

  PROBLEM: Simulation produces NaN values
  SOLUTION:
    • Span must be > 0 m (minimum 1 m)
    • Chord root must be > 0.1 m
    • Mach must be between 0.05 and 3.0
    • Check that tip chord < root chord

  PROBLEM: Safety factor = Infinity
  SOLUTION:
    • Normal when simulation runs before any aerodynamic load is applied
    • Run a full simulation (F5) to generate lift loads first

  PROBLEM: npm start launches but window closes immediately
  SOLUTION:
    • Check electron-log output in %APPDATA%\travan-aero-simulator\logs\
    • Ensure dist/ folder exists and contains index.html
    • Set NODE_ENV=development and check console output

  PROBLEM: Report modal shows "—" for all values
  SOLUTION:
    • Run a complete simulation first. The report requires results from
      all three solvers (aero, FEA, mach). Press F5 for full run.

  ── BUILD / PACKAGING ISSUES ──────────────────────────────────────────────

  PROBLEM: electron-builder fails on Windows — "NSIS not found"
  SOLUTION:
    npm install --save-dev electron-builder@latest
    # electron-builder bundles NSIS internally — ensure you're on v24+

  PROBLEM: Code signing error on Windows
  SOLUTION:
    # Build without code signing:
    npx electron-builder --win --publish never
    # Or set in package.json build config:
    "win": { "signingHashAlgorithms": null, "sign": null }

  PROBLEM: dist-electron/ folder not created
  SOLUTION:
    • Must run npm run build BEFORE npm run dist
    • Or use: npm run dist (it runs build automatically)

  PROBLEM: Large installer size (>200 MB)
  SOLUTION:
    • This is normal — Electron bundles Chromium + Node.js
    • Typical range: 120–160 MB for Electron 29
    • Use electron-builder's compression: set "compression": "maximum"
